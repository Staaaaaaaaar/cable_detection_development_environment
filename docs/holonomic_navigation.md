# 全向局部导航架构

## 目标

局部导航接收 `map` 坐标系中的 `PoseStamped`，输出机器狗机体系速度。位置目标和
姿态目标是同一个 Goal Pose 的组成部分，但控制时相互独立：机器人可以侧移、斜移，
也可以在平移过程中调整 yaw。

## 组件职责

### localPlanner

源码：`src/local_planner/src/localPlanner.cpp`

1. 接收定位、目标和局部点云；
2. 将点云转换到当前 `vehicle` 坐标系；
3. 以 `candidateAngleStep` 为间隔生成 360 度平移候选；
4. 沿候选路径以 `pathResolution` 采样机器人足迹；
5. 对硬障碍、地形代价和旋转扫掠区域进行检查；
6. 选择评分最高的路径发布到 `/path`。

候选评分包含：

- 相对原目标距离的进展；
- 与目标方向的夹角；
- 安全可执行长度；
- 地形代价；
- 相邻规划周期的方向变化；
- 根据前向/侧向速度上限估算的执行时间。

规划器不再读取 PLY 轨迹文件，也不依赖四轮车曲率或最小转弯半径。

### pathFollower

源码：`src/local_planner/src/pathFollower.cpp`

跟随器把局部路径点转换为当前机体系位置误差，并生成 `vx/vy`。`yaw_rate` 直接依据
Goal Pose 的 yaw 误差生成，因此机体朝向不需要与路径切线一致。

最终 Pose servo 必须同时满足：

1. 规划器发布了至少两个路径点；
2. 路径末端与 Goal 位置在 2 cm 内匹配；
3. 当前位置进入 `poseServoDisThre`。

单点 `/path` 表示规划器没有找到安全路径，跟随器会立即输出零速度。

## 碰撞模型

平移碰撞足迹是轴对齐于当前机体的矩形：

```text
half_length = vehicleLength / 2 + safetyMargin
half_width  = vehicleWidth  / 2 + safetyMargin
```

默认 `vehicleLength=0.7`、`vehicleWidth=0.4`、`safetyMargin=0.1`，因此有效碰撞
Box 为 `0.9 m × 0.6 m`。

当目标 yaw 与当前 yaw 的差值超过 `goalYawTolerance` 时，规划器使用矩形外接圆检查
扫掠区域。默认半径约为：

```text
sqrt(0.45^2 + 0.30^2) = 0.54 m
```

该方法比只检查目标姿态更保守，但可以避免边移动边旋转时机身角部碰撞。

## 速度合法化

机器狗 SDK 的每个轴存在不连续合法区间。跟随器先计算连续控制量，再执行：

1. 单轴误差死区；
2. 导航速度上限和硬件轴上限裁剪；
3. 合法最小非零速度吸附；
4. 加速度限制；
5. 换向前回零；
6. 安全状态强制立即回零。

如果两个平移轴吸附到最小速度后导致合速度超过导航上限，只保留相对贡献更大的轴，
避免低速阶段发生非预期斜向漂移。

## 能力边界

这是局部反应式规划器，不维护全局栅格，也不保证绕过大型 U 形障碍。如果任务需要跨越
长距离或复杂拓扑，应由上层全局规划器提供中间 Goal Pose，本模块负责局部执行和避障。
`/goal_pose` 当前约定使用 `map` 坐标系，节点不会自动转换其他 frame。
